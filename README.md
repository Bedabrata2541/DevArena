DevArena (UI)
Hackathons & Coding Contests — All in One Place
DevArena is a centralized platform that helps developers, students, and tech enthusiasts discover, track, and participate in hackathons and coding contests across multiple platforms — all from a single place.

Why DevArena?
Finding the right hackathons and contests is often scattered across different websites and communities. DevArena solves this by bringing everything together in one clean, easy-to-use interface.

One platform. Zero clutter. Maximum opportunities.

Features
🏆 Browse upcoming hackathons & coding contests
📅 View events with clear timelines and details
🔍 Discover opportunities from multiple platforms
🧑‍💻 Built with developers in mind — clean UI & fast UX
📱 Fully responsive design for all devices
⚡ Optimized for performance and accessibility
Tech Stack
Frontend: React / Next.js
Styling: Tailwind CSS
Design: Figma (AI-assisted design)
Version Control: Git & GitHub
Designed in Figma → Built for the web with a focus on usability and scalability.

Design Philosophy
Minimal & modern UI
Clear visual hierarchy
Developer-first experience
Scalable component-based layout
Accessibility-aware design choices
